# imageavatarppt

`image-avatar-ppt` is a Codex skill for turning outlines into palette-controlled image-based PPTX decks with the Parallel Digital standard template.

It keeps chapter divider pages native to the template and inserts generated full-slide PNG content pages by chapter.

## What It Does

- Uses `assets/parallel-digital-standard-template.pptx` as the base template.
- Reuses the template chapter page and only replaces its title/subtitle text.
- Converts loose text into a central thesis, decision request, causal story arc,
  and validated chapter and slide plan.
- Records the audience question, claim type, visual focus, and page-to-page
  transition for every content slide.
- Separates the deck-level thesis from each page's narrative role and content
  boundary, preventing problem or evidence pages from prematurely stating or
  depicting the later solution.
- Chooses tables, hub-and-spoke diagrams, causal chains, flows, layers,
  comparisons, networks, or evidence boards from the information relationship
  rather than mechanically copying the source format.
- Inserts content pages as full-bleed 16:9 PNG images generated by GPT Image or MiniMax.
- Injects the user's exact palette into every image prompt.
- Optionally recolors template media and native elements to the same palette.
- Uses Kimi Vision as an optional multimodal QA reviewer.
- Produces one automatically selected best-fit image version per content slide by default.
- Requires visual inspection of generated Chinese text before insertion, especially repeated phrases, malformed characters, and text overlap.
- Uses pure white solid content-page backgrounds by default and rejects busy
  textures, gradients, scenic wallpaper, and competing decorative elements.
- Reviews the whole contact sheet for executive visual focus, deck-level
  continuity, and smooth spoken transitions.

## Assemble A Deck

Create and validate a deck plan first:

```bash
python scripts/validate_plan.py manifest.example.json
python scripts/generate_images.py manifest.example.json --dry-run
```

Paid generation requires an explicit `--confirm-paid-call` flag after user approval.
On macOS, credentials can be read from Keychain; plaintext key files are not required.

The script creates a PPTX with this order:

1. Cover page
2. Catalogue page
3. Chapter divider page
4. Content image slides
5. Closing page

Each chapter repeats steps 3-4.

## Notes

- Content images must be close to 16:9 and meet the configured minimum dimensions.
- Chapter pages are not rasterized.
- OpenAI and MiniMax generate images; Kimi reviews generated images.
- Do not generate multiple visual template options unless the user explicitly asks for alternatives.
- The user-provided source template is copied into `assets/` so the project is self-contained.
